# Document Intelligence Platform

A hackathon project demonstrating an end-to-end document intelligence pipeline:

Document Upload → Document Processing → Semantic Retrieval → Multi-Source Context → AI-Powered Response → Evidence & Source Attribution

## Project Structure

- `backend/` — Server-side application code (API, document processing, retrieval logic)
- `frontend/` — Client-side application code (UI for upload, chat/query, and results)
- `documents/` — Sample/uploaded documents used for testing the pipeline

## Status

Project scaffolding only. Implementation is being built incrementally, one step at a time.
